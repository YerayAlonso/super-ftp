# Super FTP 0.1.1 — private preview candidate

This preview adds a Preferences dialog for language, theme, interface size and update checks. It also adds an on-demand check for newer public GitHub releases and preliminary third-party notices in Help.

**Windows x64 only:** the installer is unsigned and Windows may display a security warning. **macOS and Linux builds have not yet been tested on real devices.** CI builds are not a substitute for real-device testing; no macOS or Linux installer is included.

The manual update check cannot see private releases, does not send credentials and does not download or install software. The project and this release remain private.

Third-party licensing review is still in progress; see [THIRD_PARTY_REVIEW.md](https://github.com/YerayAlonso/super-ftp/blob/main/THIRD_PARTY_REVIEW.md). This preview has not undergone an independent security audit. See the [README](https://github.com/YerayAlonso/super-ftp/blob/main/README.md#preview-limitations) for transfer and deletion limitations.
