# Changelog

Notable changes will be recorded here.

## 0.1.2 — Preview

- Integrated manual update checks, preview selection and release notes into Preferences without opening a separate dialog.
- Added scheduled and manual dependency security checks and documented the unresolved RSA timing advisory.

## 0.1.1 — Preview

- Added a manual Windows installer smoke workflow.
- Added a manual public GitHub release check with optional preview versions; no automatic downloads or installation.
- Added preliminary third-party license notices and a Windows-targeted inventory; the licensing review remains open.

## 0.1.0 — Preview

- SFTP connections with password, key-file and agent authentication, host-key verification and multiple sessions.
- Local and remote file browsing, recursive transfers, conflict decisions and permanent recursive deletion with confirmation.
- Eight interface languages, theme selection and adjustable interface size.
- Loopback SFTP integration tests, UI tests and a multi-platform CI configuration.

The application is a preview; see the [README](README.md#preview-limitations) for limitations and platform validation status.
